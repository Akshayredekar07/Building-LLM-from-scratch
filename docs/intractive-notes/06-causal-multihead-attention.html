S9 — Causal Self-Attention

Causal Self-Attention (Masked Attention)

Regular self-attention lets every token attend to every other token in the sequence — past and future alike. But during text generation, the model produces tokens one at a time. When predicting the third token, it must not peek at the fourth or fifth. Causal self-attention (also called masked attention) enforces this constraint by zeroing out all "future" attention weights. It is the key difference between a BERT-style encoder and a GPT-style decoder.

Why We Need Causal Masking
Problem: Attention Sees the Future

Standard self-attention computes scores between ALL token pairs. Token $x^1$ ("your") can see $x^5$ ("step"). This is data leakage during autoregressive generation.

Solution: Causal Mask

We force the upper-triangle of the attention score matrix to $-\infty$ before softmax. After softmax these become exactly $0$ — no information flows from future tokens.

Result: Autoregressive

Token $x^i$ can only attend to $x^1, x^2, \ldots, x^i$. The model handles generation tasks correctly: each output depends only on prior tokens.

Also Known As

Decoder self-attention, autoregressive attention, lower-triangular attention. GPT, LLaMA, Mistral all use this exact mechanism.

How it Differs from Standard Self-Attention

Standard self-attention — used in BERT (encoder). Every token attends to the entire input sequence. Mechanism is symmetric: $x^3$ can see $x^5$ and vice versa. Perfect for tasks like classification or understanding the whole sentence at once.

Causal self-attention — used in GPT (decoder). Token $x^i$ may only attend to positions $j \leq i$. This is a special form of self-attention with a lower-triangular restriction, making it suitable for sequential generation of any given token.

Core Insight: Causal masking is not about changing the attention formula — it is about restricting which positions each token is allowed to look at by setting future scores to $-\infty$ before applying softmax.
S10 — Masking Strategy

Applying a Causal Attention Mask

After computing raw attention scores $\omega_{ij} = q_i \cdot k_j^T / \sqrt{d_k}$, we apply a binary lower-triangular mask. Positions that are masked (future tokens) receive the value $-\infty$ before softmax, so they contribute zero to the weighted sum. This section derives exactly how the mask matrix is constructed and applied, with a worked example on the sentence "The cat sleeps".

Worked Example — "The cat sleeps" (T=3)

Sentence: "The cat sleeps". Tokens: $x^1 =$ "the", $x^2 =$ "cat", $x^3 =$ "sleeps". After computing all $Q, K, V$ matrices via the weight matrices $W_Q, W_K, W_V$, we get a raw score matrix:

$$\text{Raw scores} = \frac{QK^\top}{\sqrt{d_k}} = \begin{bmatrix} 5.8 & 2.0 & 1.2 \\ -1.3 & -7.0 & 1.4 \\ -5.0 & -27.4 & -1.01 \end{bmatrix}$$ $$\text{shape: } (T \times T) = (3 \times 3) \quad \text{rows = query token, cols = key token}$$
Why the Shape is (num_tokens × num_tokens)

The score matrix has shape $(T, T)$ because each of the $T$ query vectors $q_i$ computes a dot product with each of the $T$ key vectors $k_j$. For every head, we calculate $T^2$ individual attention scores. The score $\omega_{ij}$ at row $i$, column $j$ means: how much should token $i$ attend to token $j$?

$$\Omega \in \mathbb{R}^{T \times T}, \quad \omega_{ij} = \frac{q_i \cdot k_j}{\sqrt{d_k}}$$ $$\text{Because }\omega_{ij}\text{ exists for every pair }(i,j),\text{ the attention score exists between each token.}$$
Constructing the Causal Mask

We want to zero out the upper triangle (positions where $j > i$, i.e. future tokens). We create a boolean mask using torch.triu (upper triangle, diagonal offset=1):

The Mathematics: Why −∞ Works
$$\text{Masked score: }\omega_{ij}^{\text{masked}} = \begin{cases} \omega_{ij} & \text{if } j \leq i \\ -\infty & \text{if } j > i \end{cases}$$ $$\text{After softmax: }\alpha_{ij} = \frac{e^{\omega_{ij}^{\text{masked}}}}{\sum_{k=1}^{T} e^{\omega_{ik}^{\text{masked}}}}$$ $$\text{Since }e^{-\infty} = 0,\text{ masked positions contribute exactly 0 to the softmax sum.}$$ $$\text{So }\alpha_{ij} = 0 \text{ whenever } j > i \quad \Rightarrow \text{ future tokens have zero weight.}$$

PyTorch Implementation — Building the Mask
Python — Constructing and applying a causal mask 
import torch

# concept: lower-triangular causal mask for autoregressive attention
# scores shape: [batch, num_heads, T, T]  OR  [T, T] for single-head

T = 3  # sequence length: "the cat sleeps"

# Step 1: create upper-triangular boolean mask (positions we want to BLOCK)
# torch.triu(..., diagonal=1) keeps only strictly above main diagonal
mask = torch.triu(torch.ones(T, T), diagonal=1).bool()
# mask:
# [[False, True,  True ],
#  [False, False, True ],
#  [False, False, False]]

# Step 2: example raw scores from QK^T / sqrt(dk)
scores = torch.tensor([
    [ 5.8,  2.0,  1.2],
    [-1.3, -7.0,  1.4],
    [-5.0,-27.4, -1.01]
])  # shape [T, T] = [3, 3]

# Step 3: apply mask — set future positions to -inf
scores_masked = scores.masked_fill(mask, float('-inf'))
print("masked scores:", scores_masked)
# tensor([[ 5.8000,    -inf,    -inf],
#         [-1.3000, -7.0000,    -inf],
#         [-5.0000,-27.4000, -1.0100]])

# Step 4: softmax over last dim → attention weights (alpha)
import torch.nn.functional as F
alpha = F.softmax(scores_masked, dim=-1)
print("attention weights:", alpha)
# Row 1 (the): [1.0,  0.0,  0.0]   — only sees itself
# Row 2 (cat): [0.999, 0.001, 0.0]  — mostly sees "the"
# Row 3 (sleeps): [0.01, ~0.0, 0.99] — mostly sees itself
# Time: O(T²·d) | Space: O(T²)
Key Rule: The attention weights after masking always sum to 1 per row — this is guaranteed because softmax normalizes over the non-masked (finite) scores only. The $-\infty$ entries vanish in the exponential.
S11 — Masked Softmax & Scaling

Scaling, Masked Softmax, and Attention Weights

After masking, two critical steps remain before we have usable attention weights: scaling by $1/\sqrt{d_k}$ and applying softmax. Scaling prevents the dot products from growing so large that softmax saturates into near-zero gradients. This section works through the full numerical computation of attention weights for "The cat sleeps" including the stable-softmax derivation.

Scaling by head_dim
$$\text{Scale factor:} \quad \frac{1}{\sqrt{d_k}}$$ $$\text{head\_dim} = d_k = \frac{d_{\text{model}}}{\text{num\_heads}}$$ $$\text{If } d_{\text{model}} = 6,\; \text{num\_heads} = 2 \implies d_k = 3,\; \frac{1}{\sqrt{3}} \approx 0.577$$ $$\text{Scaled scores:} \quad \hat{\omega}_{ij} = \frac{q_i \cdot k_j}{\sqrt{d_k}}$$

Without scaling, dot products grow proportionally to $\sqrt{d_k}$ (since each element has unit variance and there are $d_k$ terms). Large values push softmax into a regime where gradients vanish — the network stops learning. Dividing by $\sqrt{d_k}$ keeps the dot products numerically stable.

Full Numerical Example: Softmax After Masking

Working through token $x^3$ = "sleeps" (row 3 of score matrix). After masking, row 3 is $[-5.0,\; -27.4,\; -1.01]$.

$$\text{Row 3 masked scores:}\; \hat{\omega}_{3,:} = [-5.0,\; -27.4,\; -1.01]$$ $$\text{Divide by }\sqrt{d_k} = \sqrt{3} \approx 1.732:$$ $$\hat{\omega}_{3,:}^{\text{scaled}} = \left[\frac{-5.0}{1.732},\; \frac{-27.4}{1.732},\; \frac{-1.01}{1.732}\right] = [-2.887,\; -15.820,\; -0.583]$$ $$\text{Apply stable softmax (subtract max = }-0.583\text{):}$$ $$e^{-2.887-(-0.583)} = e^{-2.304} \approx 0.100$$ $$e^{-15.820-(-0.583)} = e^{-15.237} \approx 2.40 \times 10^{-7} \approx 0$$ $$e^{-0.583-(-0.583)} = e^{0} = 1.000$$ $$\text{Sum} = 0.100 + 0 + 1.000 = 1.100$$ $$\alpha_{3,:} = \left[\frac{0.100}{1.100},\; \frac{0}{1.100},\; \frac{1.000}{1.100}\right] \approx [0.09,\; 0.00,\; 0.91]$$

Token "sleeps" ($x^3$) attends 91% to itself and 9% to "the" ($x^1$). The intermediate token "cat" ($x^2$) gets essentially zero weight because its score $-27.4$ was far below the others — it's just a very negative dot product for this head, not because of masking (though it is also a valid past token).

Stable Softmax Formula
$$\text{Standard softmax:}\; \alpha_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$ $$\text{Numerically stable softmax:}\; \alpha_i = \frac{e^{z_i - z_{\max}}}{\sum_j e^{z_j - z_{\max}}}$$ $$\text{Subtracting }z_{\max}\text{ does not change the result (it cancels), but prevents overflow: }e^{z_i - z_{\max}} \leq 1$$ $$\text{head\_dim} = \sqrt{d_k}\text{ keeps dot products from growing with embedding size.}$$
Applying Softmax to Attention Scores → Weights

After applying softmax to the masked score matrix, the resulting attention weight matrix $A \in \mathbb{R}^{T \times T}$ has the property:

  • Each row sums to 1 (probability distribution over attended tokens)
  • Upper triangle is exactly 0 (causal masking enforced)
  • Diagonal and below can have any non-negative values

Python — Full masked-softmax attention weights computation 
import torch
import torch.nn.functional as F
import math

# concept: scaled masked softmax for causal self-attention
# scores: raw dot-products QK^T, shape [T, T]

T, d_model, num_heads = 3, 6, 2
d_k = d_model // num_heads  # = 3, head dimension

scores = torch.tensor([
    [ 5.8,  2.0,  1.2],
    [-1.3, -7.0,  1.4],
    [-5.0,-27.4, -1.01]
])  # [T=3, T=3]

# Step 1: scale by 1/sqrt(d_k) for numerical stability
scores = scores / math.sqrt(d_k)  # [3, 3], values ~3x smaller

# Step 2: build causal mask and apply
mask = torch.triu(torch.ones(T, T), diagonal=1).bool()
scores = scores.masked_fill(mask, float('-inf'))

# Step 3: softmax → attention weights alpha
# dim=-1: each ROW is normalized to sum=1
alpha = F.softmax(scores, dim=-1)
print("attention weights alpha:", alpha)
print("row sums (should be 1.0):", alpha.sum(dim=-1))
# Time: O(T²) | Space: O(T²) for the attention matrix
Two-step flow to remember: (1) Compute raw scores $QK^\top/\sqrt{d_k}$. (2) Mask future positions with $-\infty$. (3) Apply row-wise softmax → get $\alpha$ weights. (4) Weighted sum: $Z = \alpha V$. The masking and scaling happen between the raw score and softmax steps.
S12 — Causal Attention as nn.Module

Implementing Causal Self-Attention in PyTorch

We now implement a complete CausalAttention class that wraps all the steps above into a reusable PyTorch module. The class incorporates trainable weight matrices $W_Q, W_K, W_V$, the causal mask, scaled-dot-product attention, and dropout — making it a production-ready component that can be dropped into a GPT-style transformer block.

Step-by-Step Construction
STEP 1 of 5
__init__: Weight Matrices + Mask Registration

Define $W_Q, W_K, W_V$ as nn.Linear(d_in, d_out, bias=False). Register the lower-triangular mask as a buffer (not a parameter — it never gets gradients). Also add dropout.

$$W_Q, W_K, W_V \in \mathbb{R}^{d_{\text{in}} \times d_{\text{out}}}$$ $$\text{mask}_{ij} = \begin{cases}1 & j \leq i \\ 0 & j > i\end{cases} \quad \text{(stored as buffer, not trained)}$$
Use register_buffer so the mask is moved to GPU with .to(device) automatically — without being included in model.parameters().
STEP 2 of 5
forward: Compute Q, K, V

Project the input $X$ through each weight matrix. Input shape: $[b, T, d_{\text{in}}]$. Output shapes: $Q, K, V \in \mathbb{R}^{b \times T \times d_{\text{out}}}$.

$$Q = X W_Q^\top, \quad K = X W_K^\top, \quad V = X W_V^\top$$ $$\text{Shapes: } X[b,T,d_{in}] \times W_Q[d_{in},d_{out}] \to Q[b,T,d_{out}]$$
Linear layers apply the projection to the last dimension, handling batch and sequence dims automatically.
STEP 3 of 5
Compute Attention Scores

Batch matrix multiplication: $\omega = Q \cdot K^\top / \sqrt{d_{\text{out}}}$. The transpose is on the last two dims.

$$\omega = \frac{Q K^\top}{\sqrt{d_{\text{out}}}}$$ $$Q[b,T,d] \times K^\top[b,d,T] \to \omega[b,T,T]$$ $$\text{Using: }\texttt{torch.bmm(Q, K.transpose(1,2))} \;\text{or}\; Q @ K.\text{transpose}(-2,-1)$$
For batched inputs, bmm (batch matrix multiply) handles the $b$ dimension automatically.
STEP 4 of 5
Apply Mask and Softmax

Truncate the mask to the actual sequence length $T$ (it was registered for max context window), fill upper triangle with $-\infty$, then apply row-wise softmax.

$$\omega^{\text{masked}}_{ij} = \begin{cases}\omega_{ij} & j \leq i \\ -\infty & j > i\end{cases}$$ $$\alpha = \text{softmax}(\omega^{\text{masked}}, \text{dim}=-1), \quad \alpha[b,T,T]$$
Slice the registered mask to [:T, :T] — this supports variable-length sequences smaller than the max context window.
STEP 5 of 5
Context Vectors Z = αV

Weighted sum of value vectors using attention weights. Apply dropout after computing weights. The output $Z$ has the same shape as the input $X$.

$$Z = \text{dropout}(\alpha) \cdot V$$ $$\alpha[b,T,T] \times V[b,T,d] \to Z[b,T,d]$$ $$\text{Dropout applied to }\alpha\text{ randomly zeroes some attention connections during training.}$$
Final output: $Z \in \mathbb{R}^{b \times T \times d_{\text{out}}}$ — same shape as input projected to $d_{\text{out}}$. Ready for the next transformer block layer.
Step 1 of 5
Complete CausalAttention Class
Python — Full CausalAttention nn.Module (GPT-style) 
import torch
import torch.nn as nn
import torch.nn.functional as F

class CausalAttention(nn.Module):
    """
    concept: single-head causal self-attention with trainable W_Q, W_K, W_V.
    Incorporates lower-triangular mask (causal/autoregressive constraint),
    scaled dot-product, softmax, and dropout.
    Input:  X [batch, seq_len, d_in]
    Output: Z [batch, seq_len, d_out]
    Time: O(T²·d) | Space: O(T²) for attn matrix
    """
    def __init__(self, d_in, d_out, context_length, dropout, qkv_bias=False):
        super().__init__()
        self.d_out = d_out

        # Trainable projection matrices — shape [d_out, d_in]
        self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
        self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)
        self.W_value  = nn.Linear(d_in, d_out, bias=qkv_bias)

        self.dropout = nn.Dropout(dropout)

        # Register causal mask as buffer: lower-triangular ones, shape [ctx, ctx]
        # buffer moves to GPU with model, but is NOT a trainable parameter
        self.register_buffer(
            'mask',
            torch.tril(torch.ones(context_length, context_length))
        )  # shape [context_length, context_length]

    def forward(self, x):
        b, T, d_in = x.shape  # batch, seq_len, embedding_dim

        # Step 1: Project to Q, K, V — shape [b, T, d_out]
        Q = self.W_query(x)  # [b, T, d_out]
        K = self.W_key(x)    # [b, T, d_out]
        V = self.W_value(x)  # [b, T, d_out]

        # Step 2: Scaled attention scores — shape [b, T, T]
        # K.transpose(-2,-1) swaps last two dims: [b, d_out, T]
        attn_scores = Q @ K.transpose(-2, -1)  # [b, T, T]
        attn_scores = attn_scores / (self.d_out ** 0.5)  # scale by 1/sqrt(d_out)

        # Step 3: Apply causal mask — slice to actual seq length T
        # self.mask[:T, :T] allows variable-length inputs
        attn_scores = attn_scores.masked_fill(
            self.mask[:T, :T] == 0,
            float('-inf')
        )  # [b, T, T], upper triangle = -inf

        # Step 4: Softmax + dropout → attention weights alpha
        attn_weights = F.softmax(attn_scores, dim=-1)  # [b, T, T]
        attn_weights = self.dropout(attn_weights)

        # Step 5: Weighted sum of values → context vectors
        Z = attn_weights @ V  # [b, T, T] × [b, T, d_out] → [b, T, d_out]
        return Z

# Quick test
torch.manual_seed(42)
d_in, d_out = 6, 3
ca = CausalAttention(d_in=d_in, d_out=d_out, context_length=10, dropout=0.0)
x  = torch.randn(2, 5, d_in)   # [batch=2, T=5, d_in=6]
Z  = ca(x)
print("input  shape:", x.shape)   # [2, 5, 6]
print("output shape:", Z.shape)   # [2, 5, 3]
Dropout in Attention

Masking adds additional attention weight zeroing — it randomly sets some attention weights to 0 during training. This prevents overfitting by forcing the model to learn attention patterns that don't always rely on the same token pairs. Dropout is applied after softmax (to $\alpha$), not before. It is a drop technique: randomly selected hidden nodes (here: attention connections) are ignored, preventing overfitting and improving generalization. Used alongside causal attention in all major transformer architectures.

Implementation Summary: Register the lower-triangular mask as a buffer so it travels with the model to GPU/CPU. Use masked_fill with -inf to block future tokens. Apply dropout to attention weights after softmax for regularization.
S13 — Multi-Head Attention Overview

Multi-Head Attention Mechanism

A single attention head learns one type of relationship between tokens. Multi-head attention splits the attention mechanism into multiple parallel heads — each head learns to focus on a different aspect of the input. For example, one head might track syntactic dependencies while another tracks semantic similarity. The outputs from all heads are then concatenated and linearly projected back to the model dimension.

Core Idea — Why Multiple Heads?
Single Head Limitation

One attention head can only capture one type of relationship per layer. Complex language has many simultaneous patterns — syntax, semantics, co-reference, position.

Multi-Head Solution

Split $d_{\text{model}}$ into $h$ heads, each of dimension $d_k = d_{\text{model}}/h$. Each head operates in a lower-dimensional subspace and learns a different pattern.

Parallel Processing

All heads run simultaneously — computationally efficient. The result of multiplying input by key-value weight matrices differs for each head due to separate weight matrices.

Combine & Project

Concatenate all head outputs: $[z_1; z_2; \ldots; z_h]$. Then project with $W_O \in \mathbb{R}^{(h \cdot d_k) \times d_{\text{model}}}$ back to original dimension.

High-Level Architecture Diagram
Key Dimensions in Multi-Head Attention
$$d_{\text{model}} = \text{embedding dimension (e.g. 512, 768)}$$ $$h = \text{number of heads (e.g. 8, 12)}$$ $$d_k = d_v = \frac{d_{\text{model}}}{h} \quad \text{(head dimension)}$$ $$\text{e.g. } d_{\text{model}}=512,\; h=8 \implies d_k = 64$$ $$\text{Each head: } W_Q^i, W_K^i, W_V^i \in \mathbb{R}^{d_{\text{model}} \times d_k}$$ $$\text{Output projection: } W_O \in \mathbb{R}^{h \cdot d_k \times d_{\text{model}}} = \mathbb{R}^{d_{\text{model}} \times d_{\text{model}}}$$

S14 — Multi-Head Attention Mathematics

MHA: Full Mathematical Derivation with Worked Example

We now work through the complete mathematics of multi-head attention, including all tensor reshape operations. The key insight is that instead of maintaining separate weight matrices for each head, we project the full embedding once and then split (reshape) the result into multiple heads — this is equivalent but far more efficient as it avoids multiple sequential matrix multiplications.

Setup: Input Tensor Shapes

We use a small example throughout: batch=1, num_tokens=3 (T), d_model=6, num_heads=2, head_dim=3. Input $X \in \mathbb{R}^{1 \times 3 \times 6}$.

$$X = \text{Input tensor, shape } (b, T, d_{\text{model}}) = (1, 3, 6)$$ $$W_Q \in \mathbb{R}^{d_{\text{model}} \times d_{\text{model}}} = \mathbb{R}^{6 \times 6}$$ $$\text{num\_heads} = 2, \quad \text{head\_dim} = 6/2 = 3$$
Step 1 — Queries, Keys, Values (Full Projection)

Project $X$ through the combined weight matrices to get full-size Q, K, V. Unlike single-head, here $W_Q \in \mathbb{R}^{d_{\text{model}} \times d_{\text{model}}}$ (not $d_{\text{model}} \times d_k$).

$$Q = X W_Q, \quad K = X W_K, \quad V = X W_V$$ $$X[1,3,6] \times W_Q[6,6] \to Q[1,3,6]$$

$W_Q = \begin{bmatrix}0.6&0.23&1.24&0.26&0.34&-0.32\\ 0.1&-0.93&0.53&0.34&1.26&-1.6\\\ldots\end{bmatrix}_{6\times6}$   $Q = X W_Q^\top \Rightarrow Q[1,3,6]$

Step 2 — Unroll Last Dimension into (num_heads × head_dim)

Instead of keeping one big $[b, T, d_{\text{model}}]$ tensor, reshape it so dimension is split: $d_{\text{model}} = \text{num\_heads} \times \text{head\_dim}$.

$$Q[b, T, d_{\text{model}}] \;\xrightarrow{\text{reshape}}\; Q[b, T, h, d_k]$$ $$\text{Example: }Q[1,3,6] \to Q[1,3,2,3]$$ $$\text{Then transpose to group by head first:}$$ $$Q[b,T,h,d_k] \;\xrightarrow{\text{transpose(1,2)}}\; Q[b,h,T,d_k]$$ $$\text{Example: }Q[1,3,2,3] \xrightarrow{\text{transpose}} Q[1,2,3,3]$$ $$\text{Now: batch=1, heads=2, tokens=3, head\_dim=3}$$

Step 3 — Per-Head Attention Scores

For each head $i$, compute $QK^\top / \sqrt{d_k}$. With shape $[b, h, T, d_k]$, batched matmul automatically handles both the batch and head dimensions simultaneously.

$$\text{Scores}_h = \frac{Q_h \cdot K_h^\top}{\sqrt{d_k}}, \quad Q_h[b,T,d_k] \times K_h^\top[b,d_k,T] \to \text{Scores}_h[b,T,T]$$ $$\text{With batched matmul over heads: } Q[b,h,T,d_k] \times K[b,h,d_k,T] \to \Omega[b,h,T,T]$$ $$\sqrt{d_k} = \sqrt{3} \approx 1.732$$
Step 4 — Apply Causal Mask (same as single-head)
$$\Omega^{\text{masked}}_{b,h,i,j} = \begin{cases}\Omega_{b,h,i,j} & j \leq i \\ -\infty & j > i\end{cases}$$ $$\alpha = \text{softmax}\!\left(\Omega^{\text{masked}}, \text{dim}=-1\right), \quad \alpha \in [0,1]^{b \times h \times T \times T}$$
Critical: The causal mask is applied identically across all heads — every head must obey the same left-to-right constraint. The mask shape is $[T, T]$ and broadcasts across the batch and head dimensions.
Step 5 — Context Vectors per Head, then Combine
$$Z_h = \alpha_h \cdot V_h, \quad \alpha_h[b,T,T] \times V_h[b,T,d_k] \to Z_h[b,T,d_k]$$ $$\text{Stacked across all heads: } Z[b,h,T,d_k]$$ $$\xrightarrow{\text{transpose(1,2)}} Z[b,T,h,d_k] \xrightarrow{\text{reshape}} Z[b,T,h \cdot d_k] = Z[b,T,d_{\text{model}}]$$ $$\text{Example: }Z[1,2,3,3] \to Z[1,3,2,3] \to Z[1,3,6]$$
Step 6 — Output Projection W_O
$$\text{MHA}(Q,K,V) = \text{Concat}(Z_1,\ldots,Z_h) \cdot W_O$$ $$Z_{\text{concat}}[b,T,d_{\text{model}}] \times W_O[d_{\text{model}},d_{\text{model}}] \to \text{Output}[b,T,d_{\text{model}}]$$ $$W_O \in \mathbb{R}^{d_{\text{model}} \times d_{\text{model}}} \quad\text{(learned linear projection)}$$

The concatenated output $[Z_1; Z_2; \ldots; Z_h]$ contains the outputs from all heads stacked side-by-side. $W_O$ (output projection) mixes information across heads — it lets the model combine insights from all heads into a single coherent representation. Without $W_O$, the heads would be independent and their outputs couldn't interact. For the context vector, choosing the embedding dimension of $d_{\text{model}}$ results in a final output of $d \times \text{num\_heads}$.

Complete Shape Transformation Table
OperationInput ShapeOutput ShapeNotes

Key Insight: The reshape + transpose trick means we never actually create separate Q/K/V matrices for each head. We do ONE big matrix multiply, then logically slice the result. This is much faster than $h$ separate projections and is how all production transformers work.
S15 — Multi-Head Attention Implementation

Implementing Multi-Head Causal Attention in PyTorch

Now we build the complete MultiHeadAttention class. The implementation uses the efficient "split after projection" approach — one set of large weight matrices rather than $h$ separate small ones. We also add a MultiHeadAttentionWrapper that stacks multiple single-head CausalAttention objects, showing both approaches side-by-side.

Approach A — Wrapper (Stack Multiple Single Heads)

Instead of maintaining two separate causal attention wrappers and multi-head attention, we can combine both causal and multi-head attention. The wrapper uses nn.ModuleList to hold $h$ independent CausalAttention instances, runs them in parallel (via a list comprehension), concatenates along the last dim, then applies $W_O$. This is a single MultiHeadAttentionClass that can combine both causal and multi-head at once.

Python — MultiHeadAttentionWrapper (stacks h CausalAttention heads) 
import torch
import torch.nn as nn

class MultiHeadAttentionWrapper(nn.Module):
    """
    concept: wrapper combining h CausalAttention heads, then W_O projection.
    Simpler to understand but slower — runs heads sequentially.
    Input:  X  [batch, T, d_in]
    Output: Z  [batch, T, d_out * num_heads]  → projected to [batch, T, d_out*h]
    """
    def __init__(self, d_in, d_out, context_length, dropout, num_heads, qkv_bias=False):
        super().__init__()
        # h independent CausalAttention heads in a ModuleList
        self.heads = nn.ModuleList([
            CausalAttention(d_in, d_out, context_length, dropout, qkv_bias)
            for _ in range(num_heads)
        ])
        # output projection W_O: [num_heads*d_out, num_heads*d_out]
        self.out_proj = nn.Linear(num_heads * d_out, num_heads * d_out)

    def forward(self, x):
        # Run each head independently, then concatenate along last dim
        head_outputs = [head(x) for head in self.heads]  # h × [b,T,d_out]
        Z = torch.cat(head_outputs, dim=-1)              # [b, T, h*d_out]
        Z = self.out_proj(Z)                              # [b, T, h*d_out]
        return Z

# Test
mha_wrap = MultiHeadAttentionWrapper(
    d_in=6, d_out=3, context_length=10,
    dropout=0.0, num_heads=2
)
x = torch.randn(1, 3, 6)
print("wrapper output:", mha_wrap(x).shape)  # [1, 3, 6]
Approach B — Efficient MultiHeadAttention (Single Split)

The production-grade approach: project once to full dimension, then reshape and transpose to get per-head Q/K/V. All heads run in a single batched matmul — much faster than the wrapper approach, especially on GPU.

Python — Efficient MultiHeadAttention (single projection + reshape) 
import torch
import torch.nn as nn
import torch.nn.functional as F

class MultiHeadAttention(nn.Module):
    """
    concept: efficient multi-head causal self-attention via reshape + batched matmul.
    Single W_Q/W_K/W_V projection → split into h heads → parallel attention → concat → W_O.
    Input:  X [b, T, d_model]
    Output: Z [b, T, d_model]
    Time: O(h · T² · d_k) = O(T² · d_model) | Space: O(h · T²)
    """
    def __init__(self, d_model, num_heads, context_length, dropout, qkv_bias=False):
        super().__init__()
        # Precondition: d_model must be divisible by num_heads
        assert d_model % num_heads == 0, "d_model must be divisible by num_heads"

        self.num_heads = num_heads
        self.d_model   = d_model
        self.head_dim  = d_model // num_heads  # d_k per head

        # Single large projection for all heads combined
        # Shape: [d_model, d_model] — will be split later
        self.W_query = nn.Linear(d_model, d_model, bias=qkv_bias)
        self.W_key   = nn.Linear(d_model, d_model, bias=qkv_bias)
        self.W_value  = nn.Linear(d_model, d_model, bias=qkv_bias)

        # Output projection: mix information across heads
        self.out_proj = nn.Linear(d_model, d_model)

        self.dropout  = nn.Dropout(dropout)

        # Causal mask: lower-triangular buffer
        self.register_buffer(
            'mask',
            torch.tril(torch.ones(context_length, context_length))
        )

    def forward(self, x):
        b, T, d = x.shape  # batch, seq_len, d_model
        h  = self.num_heads
        dk = self.head_dim

        # ── Step 1: Project X → Q, K, V (full d_model width) ──────────────────
        Q = self.W_query(x)   # [b, T, d_model]
        K = self.W_key(x)     # [b, T, d_model]
        V = self.W_value(x)   # [b, T, d_model]

        # ── Step 2: Reshape → split d_model into (h, d_k) ─────────────────────
        # view(-1, T, h, dk) then transpose(1,2) → [b, h, T, dk]
        Q = Q.view(b, T, h, dk).transpose(1, 2)  # [b, h, T, dk]
        K = K.view(b, T, h, dk).transpose(1, 2)  # [b, h, T, dk]
        V = V.view(b, T, h, dk).transpose(1, 2)  # [b, h, T, dk]

        # ── Step 3: Scaled attention scores ───────────────────────────────────
        # K.transpose(-2,-1): [b,h,dk,T]; result: [b,h,T,T]
        attn_scores = (Q @ K.transpose(-2, -1)) / (dk ** 0.5)  # [b,h,T,T]

        # ── Step 4: Causal mask (upper triangle → -inf) ───────────────────────
        attn_scores = attn_scores.masked_fill(
            self.mask[:T, :T] == 0, float('-inf')
        )  # [b, h, T, T]

        # ── Step 5: Softmax + dropout → attention weights ─────────────────────
        attn_weights = F.softmax(attn_scores, dim=-1)   # [b, h, T, T]
        attn_weights = self.dropout(attn_weights)

        # ── Step 6: Context vectors Z = α · V ─────────────────────────────────
        Z = attn_weights @ V  # [b,h,T,T] × [b,h,T,dk] → [b, h, T, dk]

        # ── Step 7: Recombine heads ───────────────────────────────────────────
        # transpose: [b,h,T,dk] → [b,T,h,dk]
        # contiguous() required before view() if memory is non-contiguous after transpose
        # view: [b,T,h,dk] → [b,T,d_model]   (merge heads back)
        Z = Z.transpose(1, 2).contiguous().view(b, T, d)  # [b, T, d_model]

        # ── Step 8: Output projection W_O ─────────────────────────────────────
        Z = self.out_proj(Z)  # [b, T, d_model]
        return Z

Why .contiguous() Before .view()?

After .transpose(1,2), the tensor's data in memory is non-contiguous — the stride ordering doesn't match physical memory. .view() requires contiguous memory to safely reshape. .contiguous() creates a fresh contiguous copy. Alternatively use .reshape() which handles this automatically (but may copy internally anyway).
