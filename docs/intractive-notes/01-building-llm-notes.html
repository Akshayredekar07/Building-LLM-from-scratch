01 — Definition

WHAT IS AN LLM?

A Large Language Model is a deep neural network designed to understand and generate human-like text. It is trained on a massive amount of text data.

Neural Network

Deep neural network at its core — not a rule-based system. Learns patterns from data rather than being explicitly programmed.

Human-like Text

Responds to human-like text and generates text. The input and output are both natural language.

Massive Training Data

Trained on enormous amounts of text data — web crawls, books, Wikipedia, code, and more. Scale is the key ingredient.

02 — Motivation

WHY LARGE LANGUAGE MODELS?

Models have billions of parameters — this gives them the capacity to learn complex patterns across the full range of human language.

LLMs are capable of a wide range of NLP tasks — question answering, sentiment analysis, text generation, machine translation, summarization, and much more.

06 — Pretraining Phase

PRETRAINING

Pretraining is unsupervised learning — the model is first trained on unlabelled data to learn general patterns. After this it is finetuned on supervised data for specific tasks.

The model learns general patterns from raw text without any labelling. This is what gives LLMs their broad capabilities — they absorb the structure of language itself.

What Pretraining Produces

The result is a Pretrained (Foundational) LLM — also called a base model or foundation model. It is:

  • Trained on unlabelled text (raw billions of words)
  • Not yet trained on labelled data
  • Capable of basic language understanding — predicting next word or filling missing tokens

Pretraining Phase — What Happens

Pretraining Step-by-Step
Step 1 — Initialize Architecture

Build the LLM architecture (e.g. transformer-based). Define number of layers, attention heads, embedding dimensions, context window.

Step 2 — Feed Raw Text

Feed billions of tokens from CommonCrawl, books, Wikipedia into the model. No labels — just raw text.

Step 3 — Next Token Prediction

The model predicts the next word/token at every step. For GPT-3 this means predicting the next token given the previous 2048 tokens. The loss is cross-entropy between predicted and actual next token.

Step 4 — Foundation Model

After training on 300+ billion tokens, the model has internalised grammar, facts, reasoning patterns, and world knowledge. This is the foundation model — ready for finetuning.

07 — Finetuning Phase

FINETUNING

Finetuning takes the pretrained foundation model and refines it on a narrower, labelled dataset specific to a particular task or domain.

Finetuning on Labelled Dataset (Classification)

The pretrained LLM is finetuned on a labelled dataset for classification tasks:

  • Classification — text classification, sentiment analysis, NER
  • Text Generation — constrained generation for specific domains
  • Summarization — document summarization with reference summaries
  • Personal assistant — question answering, sentiment analysis

Input: labelled pairs (text, label). Output: a classifier built on top of the LLM backbone.

Instruction Finetuning

The model is finetuned on an instruction dataset — pairs of (instruction, desired response). This is how models like ChatGPT are created from a base GPT model.

Teaches the model to follow instructions, not just complete text. The resulting model is sometimes called an "instruction-tuned" model or a personal assistant model.

Instructional finetuning → (Global dataset with task pairs, desired answers) → Model that follows instructions

Domain-Specific Finetuning

Finetune on domain data to improve accuracy in a selected domain — medical, legal, code, financial.

  • Finetuned on admin notes → Question answering / Q&A generation
  • Finetuned on domain data → Summarization / Sentiment Analyst
  • Finetuned on user-specific data → Personalized Agent
08 — Architecture

TRANSFORMER ARCHITECTURE

What makes LLMs so powerful? The Transformer architecture. Most modern LLMs are based on it.

This architecture comes from the paper "Attention is All You Need" by Google in 2017. It replaced traditional RNN/CNN-based NLP models.

Attention is key — it allows the model to focus on relevant parts of the input sequence based on their importance relative to others, regardless of position.

Encoder

Converts input text into vector representations. Captures context from the full input sequence. Used in BERT-style models.

Decoder

Generates output text word by word. Used in GPT-style models. At each step it produces one word at a time.

Embeddings

Maps tokens to dense vector representations. The model operates entirely in this vector space — not on raw text.

Encoder–Decoder vs Encoder-Only vs Decoder-Only

ArchitectureExampleUsed For
Encoder + DecoderOriginal Transformer (2017)Translation, summarization
Encoder onlyBERTClassification, understanding tasks
Decoder onlyGPT seriesText generation, completion
This "reduced" transformer architecture — where GPT uses only the decoder block — is simpler. All you need to provide is "parse one word at a time" and the model completes the next token. Output is one word at a time.
09 — Attention Mechanism

ATTENTION MECHANISM

Attention allows the model to assign weights to different tokens in the input based on their importance relative to others.

Attention helps the model to focus on relevant parts of the sentence and capture long-range dependencies.

Why Attention Matters

In The lion roams in the jungle — to predict the next word, the model needs to know that "lion" is the subject. Attention lets the model assign high weight to "lion" even if it is far back in the sequence.

Attention — Intuition

When processing any token, attention looks at every other token in the context and scores how relevant each one is. High-scoring tokens get more influence on the current token's representation.

QUERY
Current token asking: "what is relevant to me?"
KEY
Every token broadcasting: "here is what I represent"
VALUE
Actual content weighted by attention scores

Attention is also key to positional awareness — the model learns how tokens relate to each other based on their position in the input sequence.

10 — Model Variants

BERT vs GPT

Both are LLMs built on the Transformer. They differ in which part of the transformer they use and how they are trained.

BERT — Bidirectional Encoder

Encoder-only transformer. Uses encoder only, learns from context in both directions. Trained on masked language modeling — predict masked tokens. Excellent for classification, NER, question answering.

GPT — Generative Pretrained Transformer

Decoder-only transformer. Uses decoder only, reads only left-to-right context. Generative pretrained transformer — predicts the next token. Excellent for text generation and completion.

11 — GPT Deep Dive

A CLOSER LOOK AT GPT

Unsupervised Pretraining

The model is first trained on unlabelled data to learn general patterns. After this it is finetuned on supervised data for specific tasks.

  • Model is first trained on unlabelled data
  • Learns general patterns
  • After this, finetuned on supervised, specific data

Next Word Prediction — The Core Task

GPT is trained for next word prediction — predicting the next token given all previous tokens. This is self-supervised learning: input sentence is used as both data and label.

Training Example — Next Word Prediction

Input: "Second law of robotics is:" → Model predicts "a" → correct: "robot"

Zero-Shot, Few-Shot, and Fine-Shot Learning

Learning Paradigms — Interactive

Zero-Shot Learning — ability to completely generalize to unseen tasks without any prior specific examples.

Ex: Completing a task without seeing similar examples at all.

Zero-Shot: Translate English → French
English: Hello → French: bonjour
English: goodbye → French: ?

Few-Shot Learning — learning from minimal number of examples provided by the user as input. Complete a task with only a few examples given.

Few-Shot: Translate (complete task with few examples provided)
English: Hello → French: bonjour
English: goodbye → French: au revoir
English: thank you → French: merci
English: good night → French: bonne nuit

Fine-Shot (Finetuning) Learning — learning from minimal number of examples, plus explicit examples provided by user as input. GPT-4 is capable of both zero-shot and few-shot learning.

Note: Zero-Shot vs Few-Shot: GPT-4 is capable of both zero-shot learning and few-shot learning.

GPT-3 Utilizes Large Dataset

Pretraining dataset of GPT-3 LLM — CommonCrawl, WebTexts, Books, Wikipedia. Token = the unit of text — you can think of it as used is there.

Many pretrained LLMs are available as open-source tools, can be used as general-purpose tools to write, extract, or edit text that was not part of training data.

12 — Emergent Behaviour

EMERGENT BEHAVIOUR

Emergent Behaviour — Ability of a model to perform tasks that it was not explicitly trained to perform.

Although GPT is trained for next word prediction, it can perform other tasks like language translation, spelling correction, text summarization, answering and many more. This is called emergent behaviour.

GPT models only trained simply on next word prediction — but it can perform other tasks like language translation. This is called emergent behaviour.

Why Does Emergence Happen?

When a model is trained on enough data and at sufficient scale, it internalises patterns beyond what was explicitly optimised. Next word prediction, done at scale on diverse text, forces the model to develop representations of grammar, facts, reasoning, and world knowledge — which then transfer to novel tasks.

Pretraining part of GPT → Unsupervised & Auto-regressive — the model also called auto-regressive model uses previous output as input for future predictions.

13 — Full Build Pipeline

FULL LLM BUILD PIPELINE

Putting it all together — from raw data to a specialized deployed model:

End-to-End Pipeline Walkthrough
Stage 1 — Data & Architecture
  1. Data Preparation & Sampling — Collect and clean training corpus (CommonCrawl, Books, Wikipedia). Tokenize. Apply data quality filters.
  2. Attention Mechanism — Design multi-head self-attention. This is the core engine that allows context-aware token processing.
  3. LLM Architecture — Stack transformer decoder blocks. Define layers, heads, embedding dim, context length.
  4. Pretraining — Train on massive unlabelled corpus via next-token prediction. This builds the foundation model.
→ Output: Building an LLM
Stage 2 — Foundation Model
  1. Training Loop — Run forward pass, compute cross-entropy loss, backprop, update weights. Repeat for hundreds of billions of tokens.
  2. Model Evaluation — Evaluate perplexity, benchmark on held-out data, check for capabilities and failure modes.
  3. Load Pretrained Weights — Checkpoint the trained weights. These become reusable starting points for all downstream finetuning.
→ Output: Foundation Model
Stage 3 — Finetuning (two paths)

Path A — Classifier

Finetune on labelled dataset with class labels. Add classification head. Output: task-specific classifier (sentiment, NER, topic labelling).

Path B — Personal Assistant

Finetune on instruction dataset (instruction, desired response pairs). Output: instruction-following assistant model.
