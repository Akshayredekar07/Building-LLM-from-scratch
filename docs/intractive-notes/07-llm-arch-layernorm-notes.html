S17 — LLM Architecture

GPT-Style LLM Architecture Overview

After understanding causal and multi-head attention, we now zoom out to see the full GPT-style LLM architecture. The model consists of three major components: a token embedding layer, a stack of transformer blocks, and a final output layer. The transformer block itself contains masked multi-head attention, feed-forward network, layer norms, dropout, and shortcut (residual) connections. The famous quote "every effort moves you forward" is used as the running example sequence throughout GPT-from-scratch implementations.

Top-Level Architecture

The output has the same form & dimensions as inputs. Each row is a 768-dim vector representing an embedded input token. For "every effort moves you": 4 tokens → 4 output vectors.

Transformer Block — Detailed Internal View

The transformer block is a key component of GPT-like LLMs. Each block has two sub-layers (attention + FFN), each preceded by a Layer Norm and followed by a Dropout + shortcut connection. The shortcut connection adds the block's input directly to its output, helping gradients flow backward through many layers.

Component Summary
Layer Norm 1 & 2

Applied before each sub-layer (pre-norm style in GPT-2). Normalizes activations across the feature dimension, stabilizing gradient flow.

Masked Multi-Head Attn

Causal self-attention from S9–S15. Computes contextual representations with lower-triangular mask enforcing autoregressive constraint.

Feed Forward Network

Two linear layers with GELU activation between them. Expands to $4 \times d_{\text{model}}$ then projects back. Applies position-wise to each token independently.

Shortcut Connections

Residual / skip connections: add block input directly to block output. Prevents vanishing gradients in deep stacks (N=12 for GPT-2).

Input/Output Token Vectors

For the example sentence "every effort moves you" with d_model=768:

$$\text{Input:} \quad X \in \mathbb{R}^{4 \times 768}$$ $$X = \begin{bmatrix} 0.22 & 0.34 & \cdots & 0.46 \\ 0.22 & \cdots & \cdots & 0.75 \\ 0.69 & \cdots & \cdots & 0.69 \\ 0.08 & \cdots & \cdots & 0.58 \end{bmatrix} \leftarrow \begin{array}{l} \text{"every"} \\ \text{"effort"} \\ \text{"moves"} \\ \text{"you"} \end{array}$$ $$\text{Output:} \quad Z \in \mathbb{R}^{4 \times 768} \quad \text{(same shape — critical property)}$$ $$Z = \begin{bmatrix} 0.43 & \cdots & 0.39 \\ -0.1 & \cdots & 3.65 \\ 0.4 & \cdots & 0.73 \\ 0.07 & \cdots & 0.71 \end{bmatrix}$$

Python — Skeleton GPT transformer block structure 
import torch
import torch.nn as nn

class TransformerBlock(nn.Module):
    """
    concept: one GPT-style transformer block with pre-norm and residual connections.
    x_in   : input activations [batch, T, d_model]
    x_out  : output activations [batch, T, d_model]  -- SAME SHAPE as input
    norm1  : LayerNorm before attention sub-layer
    norm2  : LayerNorm before feed-forward sub-layer
    drop   : dropout applied after each sub-layer
    Shortcut (residual): x_out = x_in + sublayer(norm(x_in))
    Time: O(T^2 * d) for attention, O(T*d^2) for FFN | Space: O(T^2 + T*d)
    dry run: x[b,T,d] → norm1 → attn → drop → +x → norm2 → ffn → drop → +prev → z[b,T,d]
    """
    def __init__(self, d_model, n_heads, context_length, drop_rate):
        super().__init__()
        self.norm1 = nn.LayerNorm(d_model)
        self.attn  = MultiHeadAttention(d_model, n_heads, context_length, drop_rate)
        self.norm2 = nn.LayerNorm(d_model)
        self.ffn   = FeedForward(d_model)
        self.drop  = nn.Dropout(drop_rate)

    def forward(self, x):
        # Attention sub-layer with pre-norm + residual
        residual = x                             # [b, T, d]  -- save for shortcut
        x = self.norm1(x)                        # [b, T, d]  -- normalize features
        x = self.attn(x)                         # [b, T, d]  -- contextual mixing
        x = self.drop(x)                         # [b, T, d]  -- regularization
        x = x + residual                         # [b, T, d]  -- shortcut 1

        # Feed-forward sub-layer with pre-norm + residual
        residual = x                             # [b, T, d]  -- save for shortcut 2
        x = self.norm2(x)                        # [b, T, d]  -- normalize
        x = self.ffn(x)                          # [b, T, d]  -- position-wise transform
        x = self.drop(x)                         # [b, T, d]  -- regularization
        x = x + residual                         # [b, T, d]  -- shortcut 2
        return x  # same shape [b, T, d] as input
Key Property: Every transformer block preserves the tensor shape $[b, T, d_{\text{model}}]$. This is why you can stack $N$ blocks sequentially — each accepts and returns the same shape. Shortcut connections ensure gradients propagate directly to early layers, bypassing $N$ matrix multiplications.

Context Length — What It Means

Q: What is context length? It is the maximum number of tokens (words/subwords) the model uses to predict the next token. With context_length=1024, when predicting token $t_{1025}$, the model can see at most tokens $t_1, t_2, \ldots, t_{1024}$. This is the "window" of memory. Modern models have much larger context windows: GPT-4 has 128K, Claude has 200K.

Every token has a 768-dim embedding vector. The vocabulary of 50,257 tokens covers English text comprehensively — each unique word (or sub-word) gets a distinct vector in $\mathbb{R}^{768}$.

Head Dimension Calculation
$$\text{head\_dim} = d_k = \frac{d_{\text{model}}}{\text{n\_heads}} = \frac{768}{12} = 64$$ $$\text{Each of the 12 heads computes attention in a 64-dim subspace}$$ $$Q_i, K_i, V_i \in \mathbb{R}^{T \times 64}, \quad i = 1, 2, \ldots, 12$$ $$\text{Scale factor:} \quad \frac{1}{\sqrt{d_k}} = \frac{1}{\sqrt{64}} = \frac{1}{8} = 0.125$$

S19 — Layer Normalization Theory

Layer Normalization: Theory & Motivation

Training deep neural networks with many layers is challenging due to vanishing and exploding gradients. Layer Normalization is a technique that normalizes activations across the feature dimension for each individual training example — independent of batch size — making it ideal for transformer architectures. It improves training stability and enhances efficiency by keeping gradients well-structured throughout training.

① Vanishing & Exploding Gradient Problem
Vanishing Gradient

Gradients shrink as they are propagated backward through layers. Weight updates become extremely small. The model learns very slowly or stops learning entirely.

Exploding Gradient

Gradients grow exponentially as they move backward. Causes very large weight updates. The model becomes unstable and diverges during training.

Root Cause

When training, the input to each layer changes as parameters of earlier layers update. This shift in distribution is called internal covariate shift.

Consequence

Unstable training dynamics, very slow convergence, model fails to generalize, loss function does not reduce properly. Requires careful initialization & small learning rates.

Internal Covariate Shift

Internal Covariate Shift: During training, the input to each layer changes as parameters of earlier layers update. This shift in distribution is called internal covariate shift. It slows down convergence, makes optimization more difficult, and requires smaller learning rates or careful initialization to compensate.

Why LayerNorm Fixes This
$$\text{Without normalization: activations } \mu \approx 0.13,\; \sigma^2 \approx 0.39 \text{ (drifting, uncontrolled)}$$ $$\text{After LayerNorm: activations } \mu = 0.00,\; \sigma^2 = 1.00 \text{ (zero mean, unit variance)}$$ $$\text{This is called \textbf{zero-mean and unit-variance normalization}}$$

S20 — Batch Normalization vs Layer Normalization

Batch Normalization vs Layer Normalization

Two dominant normalization strategies exist: Batch Normalization (BatchNorm) normalizes across the batch dimension for each feature, and Layer Normalization (LayerNorm) normalizes across the feature dimension for each individual sample. For transformers and GPT models, LayerNorm is always preferred — it is independent of batch size and works correctly with the variable-length, autoregressive nature of language model training.

a) Batch Normalization

Definition: Normalizes each feature value across the batch dimension, computing mean and variance from the entire batch for each feature separately. Given batch $\mathcal{B} = \{x^{(1)}, x^{(2)}, \ldots, x^{(m)}\}$ with $m$ samples:

$$\mu_j = \frac{1}{m} \sum_{i=1}^{m} x_j^{(i)} \quad \text{(mean of feature } j \text{ across batch)}$$ $$\sigma_j^2 = \frac{1}{m} \sum_{i=1}^{m} (x_j^{(i)} - \mu_j)^2 \quad \text{(variance of feature } j\text{)}$$ $$\hat{x}_j^{(i)} = \frac{x_j^{(i)} - \mu_j}{\sqrt{\sigma_j^2 + \epsilon}}$$ $$y_j^{(i)} = \gamma_j \hat{x}_j^{(i)} + \beta_j \quad (\gamma_j, \beta_j \text{ learnable per feature})$$

Works well with large batch sizes but can be unstable with small batch sizes. Commonly used in CNNs (convolutional neural networks) for image tasks. At inference, uses running mean/variance computed during training.

b) Layer Normalization

Definition: Normalizes each feature value of an individual data sample independently. For one sample $x = [x_1, x_2, \ldots, x_n]$ with $n$ features:

$$\mu = \frac{1}{n} \sum_{i=1}^{n} x_i \quad \text{(mean across features of THIS sample)}$$ $$\sigma^2 = \frac{1}{n} \sum_{i=1}^{n} (x_i - \mu)^2 \quad \text{(variance across features of THIS sample)}$$ $$\hat{x}_i = \frac{x_i - \mu}{\sqrt{\sigma^2 + \epsilon}} \quad \epsilon = 10^{-5} = 0.00001$$ $$y_i = \gamma \hat{x}_i + \beta \quad (\gamma, \beta \in \mathbb{R}^n \text{ learnable, one pair per feature dim})$$

Does not depend on batch size or sequence length. Transformers and GPT models often use small batches and autoregressive training (each token is generated one at a time). LayerNorm handles this naturally since each sample is normalized independently. The statistics $\mu, \sigma^2$ are computed fresh for each sample at both train and inference time.

Layer Normalization is a normalization technique applied across the features (channels/dimensions) of each individual sample. This section derives each step from scratch with a complete numerical example using $x = [4.0, 6.0, 10.0, 8.0]$, then shows the learnable scale and shift parameters $\gamma$ and $\beta$.

② Compute Mean $\mu$

Average all feature values in this single sample. This is the mean across the feature (not batch) dimension.

$$\mu = \frac{1}{n} \sum_{i=1}^{n} x_i = \frac{x_1 + x_2 + \cdots + x_n}{n}$$ $$\text{Worked: } \mu = \frac{4.0 + 6.0 + 10.0 + 8.0}{4} = \frac{28.0}{4} = 7.0$$

STEP 4 of 5
④ Normalize Each Feature $\hat{x}_i$

Subtract the mean and divide by the standard deviation. Adding $\epsilon$ prevents division by zero.

$$\hat{x}_i = \frac{x_i - \mu}{\sqrt{\sigma^2 + \epsilon}}, \quad \epsilon = 10^{-5} = 0.00001$$ $$\sqrt{\sigma^2 + \epsilon} = \sqrt{5.0 + 0.00001} \approx \sqrt{5.0} \approx 2.236$$ $$\hat{x}_1 = \frac{4.0 - 7.0}{2.236} = \frac{-3.0}{2.236} \approx -1.342$$ $$\hat{x}_2 = \frac{6.0 - 7.0}{2.236} = \frac{-1.0}{2.236} \approx -0.447$$ $$\hat{x}_3 = \frac{10.0 - 7.0}{2.236} = \frac{3.0}{2.236} \approx +1.342$$ $$\hat{x}_4 = \frac{8.0 - 7.0}{2.236} = \frac{1.0}{2.236} \approx +0.447$$ $$\hat{\mathbf{x}} = [-1.342,\; -0.447,\; +1.342,\; +0.447]$$ $$\text{Verify: mean}(\hat{\mathbf{x}}) \approx 0.000, \quad \text{var}(\hat{\mathbf{x}}) \approx 1.000$$

Magic of Zero Mean & Unit Variance: This creates consistent, balanced activation distributions that help the neural network learn faster with more stable training. Used in BatchNorm, LayerNorm, weight initialization, and input scaling.
STEP 5 of 5
⑤ Scale & Shift: Learnable $\gamma$ and $\beta$

The model learns two vectors $\gamma$ (scale) and $\beta$ (shift) — one value per feature dimension. They allow the network to undo normalization if needed.

$$y_i = \gamma_i \cdot \hat{x}_i + \beta_i$$ $$\gamma, \beta \in \mathbb{R}^n \quad \text{(trainable parameters, initialized to } \gamma=1, \beta=0\text{)}$$ $$\text{Worked: } \gamma = [1, 1, 1, 1], \quad \beta = [0, 0, 0, 0]$$ $$\mathbf{y} = \gamma \odot \hat{\mathbf{x}} + \beta = [1\cdot(-1.342) + 0,\; 1\cdot(-0.447)+0,\; 1\cdot(+1.342)+0,\; 1\cdot(+0.447)+0]$$ $$\mathbf{y} = [-1.342,\; -0.447,\; +1.342,\; +0.447]$$ $$\text{(With default init } \gamma=1, \beta=0: \text{ output equals } \hat{\mathbf{x}})$$
Why $\gamma$ and $\beta$? Pure normalization forces all features to have mean 0 and variance 1, which may not be optimal for every layer. $\gamma$ and $\beta$ give the model freedom to re-scale and re-shift the normalized output to any distribution it needs. They are learned via backpropagation.
Step 1 of 5
Complete LayerNorm Formula Summary
$$\boxed{\text{LayerNorm}(\mathbf{x}) = \gamma \odot \frac{\mathbf{x} - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta}$$ $$\mu = \frac{1}{n}\sum_{i=1}^n x_i, \quad \sigma^2 = \frac{1}{n}\sum_{i=1}^n (x_i - \mu)^2$$ $$\gamma, \beta \in \mathbb{R}^n \text{ (learnable)}, \quad \epsilon = 10^{-5} \text{ (numerical stability)}$$ $$\text{Output: zero mean, unit variance, then re-scaled by } \gamma, \text{shifted by } \beta$$

S22 — Layer Normalization in PyTorch

Implementing LayerNorm from Scratch & Using nn.LayerNorm

We implement Layer Normalization both from scratch (to see the math in code) and using PyTorch's built-in nn.LayerNorm. We also verify they produce identical outputs. Then we show where LayerNorm plugs into the full transformer block with a single-sample forward pass verification.

LayerNorm From Scratch — Full Implementation
Python — LayerNorm from scratch, matches nn.LayerNorm exactly 
import torch
import torch.nn as nn

class LayerNorm(nn.Module):
    """
    concept: layer normalization — normalize across features per sample.
    normalized_shape: tuple or int = number of feature dims to normalize
    gamma (scale): learnable weight, init=1, shape [normalized_shape]
    beta  (shift): learnable bias,  init=0, shape [normalized_shape]
    eps   : small constant (1e-5) prevents division by zero
    Precondition: x.shape[-len(normalized_shape):] == normalized_shape
    Time: O(n) per sample | Space: O(n) for gamma, beta
    dry run: x=[4,6,10,8] → mu=7.0 → var=5.0 → std=2.236
             → xhat=[-1.34,-0.45,+1.34,+0.45] → y=gamma*xhat+beta
    """
    def __init__(self, normalized_shape, eps=1e-5):
        super().__init__()
        self.eps   = eps
        # Learnable scale (gamma): init ones,  shape = [normalized_shape]
        self.gamma = nn.Parameter(torch.ones(normalized_shape))
        # Learnable shift (beta): init zeros, shape = [normalized_shape]
        self.beta  = nn.Parameter(torch.zeros(normalized_shape))

    def forward(self, x):
        # Step 1: compute mean across last dim (feature axis) per sample
        mu = x.mean(dim=-1, keepdim=True)       # [..., 1] — one mean per sample

        # Step 2: compute variance across last dim
        var = x.var(dim=-1, keepdim=True, unbiased=False)  # [..., 1]

        # Step 3: normalize — zero mean, unit variance
        x_hat = (x - mu) / torch.sqrt(var + self.eps)   # [..., n]

        # Step 4: scale and shift with learned gamma, beta
        y = self.gamma * x_hat + self.beta               # [..., n]
        return y

# --- Verification with worked example ---
x = torch.tensor([[4.0, 6.0, 10.0, 8.0]])  # [1, 4]

# Custom LayerNorm

LayerNorm with Batch of Sequences (GPT-style)

In a GPT model, input to LayerNorm is shape $[b, T, d_{\text{model}}]$. Normalization happens independently for each of the $b \times T$ token vectors across the $d_{\text{model}}$ dimension.

$$X \in \mathbb{R}^{b \times T \times d_{\text{model}}}, \quad \text{nn.LayerNorm}(d_{\text{model}})$$ $$\text{For each token at position }(b_i, t_j):\text{ compute }\mu_{b_i,t_j}, \sigma^2_{b_i,t_j}\text{ across }d_{\text{model}}\text{ features}$$ $$\text{Total normalization operations: } b \times T \text{ (one per token vector)}$$ $$\gamma, \beta \in \mathbb{R}^{d_{\text{model}}} = \mathbb{R}^{768} \text{ (same for all batch/seq positions)}$$
Python — LayerNorm for batched token sequences [b, T, d] 
import torch
import torch.nn as nn

# concept: LayerNorm applied to token embeddings in a transformer block
# x      : batched token embeddings [batch, seq_len, d_model]
# ln     : normalizes last dim (d_model) per token independently
# gamma  : scale param [d_model] — shared across all batch/seq positions
# beta   : shift param [d_model] — shared across all batch/seq positions
# Precondition: x.shape[-1] == d_model == 768 for GPT-2
# Time: O(b*T*d) | Space: O(d) for gamma, beta
# dry run: x[2,5,768] → mu[2,5,1] → var[2,5,1] → xhat[2,5,768] → y[2,5,768]

torch.manual_seed(42)
batch, T, d_model = 2, 5, 768

x = torch.randn(batch, T, d_model)  # [2, 5, 768] — raw token embeddings
ln = nn.LayerNorm(d_model)           # normalizes last dim

y = ln(x)                              # [2, 5, 768]

# Check: each token vector should have mean≈0, var≈1 after norm
# (before gamma/beta re-scaling, but default gamma=1,beta=0 so output=xhat)
print("input  shape:", x.shape)   # [2, 5, 768]
print("output shape:", y.shape)   # [2, 5, 768] — shape preserved
print("token[0,0] mean after LN:", y[0, 0].mean().item())   # ~0.0
print("token[0,0] var  after LN:", y[0, 0].var().item())    # ~1.0
print("gamma shape:", ln.weight.shape)  # [768]
print("beta  shape:", ln.bias.shape)    # [768]
print("total LN params:", 768*2)       # 1536 (gamma + beta)

LayerNorm is applied before each sub-layer (pre-norm). After the final transformer block, a third LayerNorm is applied before the output projection head. The nn.LayerNorm(d_model) call always normalizes the last dimension (feature dimension).

Numerical Stability: Why $\epsilon$?

When all feature values in a sample are identical (e.g. $x=[5.0, 5.0, 5.0, 5.0]$), the variance $\sigma^2 = 0$. Without $\epsilon$, we'd divide by $\sqrt{0} = 0$ — producing NaN/Inf gradients and crashing training. Adding $\epsilon = 10^{-5}$ ensures the denominator is always at least $\sqrt{0.00001} = 0.00316$, a safe lower bound.

Python — Single training forward pass through one GPT block with LayerNorm 
import torch
import torch.nn as nn

# concept: pre-norm transformer block — LayerNorm before each sub-layer
# x: input token embeddings [b, T, d]
# norm1, norm2: two LayerNorm instances, normalize last dim (d)
# Each sub-layer is wrapped: output = x + sublayer(norm(x))  (residual)
# Precondition: d_model divisible by n_heads
# Time: O(T^2*d) | Space: O(T*d)

d_model = 768

# Minimal pre-norm forward pass (illustrates exact position of LN)
class PreNormBlock(nn.Module):
    def __init__(self, d):
        super().__init__()
        self.norm1 = nn.LayerNorm(d)   # before attention
        self.norm2 = nn.LayerNorm(d)   # before FFN
        # placeholder sub-layers (use Identity for shape check)
        self.attn = nn.Identity()
        self.ffn  = nn.Identity()

    def forward(self, x):
        # Pre-norm + residual for attention
        x = x + self.attn(self.norm1(x))   # [b,T,d]
        # Pre-norm + residual for FFN
        x = x + self.ffn(self.norm2(x))    # [b,T,d]
        return x

# Quick shape test with 4 tokens from "every effort moves you"
block = PreNormBlock(d_model)
x_harsha = torch.randn(1, 4, d_model)  # [batch=1, T=4, d=768]
out = block(x_harsha)
print("input  shape:", x_harsha.shape)   # [1, 4, 768]
print("output shape:", out.shape)        # [1, 4, 768] — shape PRESERVED
print("LN params per block:", sum(p.numel() for p in block.parameters()))
# 768*2 + 768*2 = 3072 params (two LayerNorms each with gamma+beta)
Production Usage: In GPT-2, nn.LayerNorm(768) is instantiated twice per transformer block (before attention and before FFN) and once more before the final output head. Total LayerNorm parameters: $(12 \times 2 + 1) \times 768 \times 2 = 25 \times 1536 = 38{,}400$ — tiny relative to the 124M total.

Final Takeaway: A GPT-style transformer block = two sub-layers (attention + FFN), each preceded by a LayerNorm and followed by a residual connection. LayerNorm normalizes each token's 768-dim vector to zero mean and unit variance, then re-scales with learned $\gamma, \beta$. This is why deep stacks of 12 blocks can train stably — gradients flow cleanly through both the residual path and the normalized sub-layer path simultaneously.
